Defaults aplicados nesta rodada — fácil de corrigir

  1. Entrada: restrita a Farmacêutico/Coordenador, e só na CAF — confirmado, não é mais default (ver banner na tela de Entrada quando a unidade ativa simulada não é CAF).
  2. Relatórios financeiros: sem acesso para Atendente.
  3. Consolidado multi-unidade: só Coordenador enxerga todas as unidades nos relatórios; ações continuam restritas à unidade ativa para todos.
  4. Cadastro de usuários: fora do MVP, sem tela própria por ora.
  5. Cadastro de medicamentos: Farmacêutico cadastra sozinho, sem fluxo de aprovação.
